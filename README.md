# 七日人生 (Seven Day Life)

## 项目简介

《七日人生》是一款叙事驱动的模拟游戏，玩家将体验为期七天的紧凑人生旅程。在这个游戏中，玩家需要平衡工作、家庭和人际关系，做出关键选择，这些选择将影响角色的命运走向。

## 游戏特色

- **七天挑战**：在有限的时间内完成尽可能多的目标
- **多维度资源管理**：平衡金钱、项目进度、家庭关系和人际关系
- **选择与后果**：每个决定都会产生深远影响，导向不同结局
- **存档系统**：支持随时保存和恢复游戏进度
- **丰富的UI界面**：包含主界面、对话系统、状态显示和日历系统

## 游戏机制

### 核心资源

1. **金钱**：用于日常开销和特殊事件
2. **项目完成度**：衡量工作进展的重要指标
3. **妻子崩溃度**：反映家庭关系的健康状况
4. **后辈好感度**：影响与同事陈静的关系发展
5. **背叛选项**：可能改变游戏走向的关键选择

### 游戏流程

- 游戏按天进行，每天包含多个场景和选择
- 玩家的每个选择都会影响各项资源数值
- 特定条件会触发不同的事件和结局
- 支持随时存档和读档功能

## 技术架构

### 开发环境

- **引擎**：基于星火编辑器开发
- **脚本语言**：TypeScript + Lua
- **构建工具**：TypeScript-to-Lua (TSTL)
- **UI框架**：自定义GUI系统

### 项目结构

```
Game_Jam_Seven_Day_Life/
├── script/                 # 服务端脚本
│   ├── trigger_module_main_1.ts    # 主要游戏逻辑
│   ├── trigger_validator.ts         # 验证器
│   └── ...                          # 其他服务端脚本
├── ui/                     # 客户端UI和脚本
│   ├── script/             # 客户端脚本
│   │   ├── main.lua        # 主入口
│   │   ├── gui/            # UI界面
│   │   └── obj/            # 游戏对象
│   └── ...                 # 其他UI资源
├── editor/                 # 编辑器相关文件
├── block/                  # 游戏模块
├── table/                  # 游戏数据表
└── src/                    # 源代码
```

### 核心系统

1. **存档系统**：基于云变量的数据持久化
2. **UI系统**：模块化的界面组件，支持状态管理和事件响应
3. **对话系统**：支持分支对话和角色互动
4. **状态管理系统**：实时追踪和更新游戏资源

## 开发指南

### 环境设置

1. 安装Node.js和npm
2. 安装TypeScript-to-Lua：`npm install typescript-to-lua`
3. 配置tsconfig.json以支持TSTL编译

### 构建项目

```bash
# 编译TypeScript到Lua
cd script
npm run build

# 或者使用监视模式进行开发
npm run dev
```

### 添加新功能

1. 在`script/trigger_module_main_1.ts`中添加服务端逻辑
2. 在`ui/script/`中添加客户端逻辑
3. 在`ui/script/gui/`中创建或修改UI组件
4. 更新相应的数据表和资源文件
